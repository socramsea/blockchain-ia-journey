# Lição 01 — O Problema do Consenso

## Resumo (5 linhas)
1. A blockchain resolve o problema de várias pessoas que não confiam umas nas outras precisarem concordar sobre quem tem o quê, sem precisar de um banco no meio.
2. Cada um é responsável pela sua própria chave — não existe um banco guardando por você. Isso é auto-custódia.
3. As regras são públicas e iguais para todos. Não é "cada um tem suas regras" — é "todos aplicam a mesma regra, e ninguém precisa confiar no outro para aplicá-la".
4. Os nós da rede verificam se a transação obedece às regras, usando hashes para checar a integridade dos blocos e assinaturas digitais para checar se o dono autorizou.
5. Não dá para alterar um bloco antigo porque cada bloco contém o hash do anterior. Se alguém muda uma transação, o hash muda, o bloco seguinte quebra, e todos os blocos depois dele também — a rede rejeita a versão adulterada.
